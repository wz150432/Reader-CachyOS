上面的新笔趣阁等候选站点来自用户提供的[书城页面](http://t.chaojizhu.cn/bookstore.html)。该页面是网站导航与下载链接集合，本身不是章节书源。

当前共有 10 个内置书源，默认选择“全部书源”；同时搜索已启用且有搜索入口的书源，最多并发 3 个，结果携带原始书源，部分失败不影响其他结果。请求中可点同一按钮取消；点选已有结果会停止其余搜索并进入该来源的目录。

内置规则随程序提供，已有 `sources.json` 也会载入新增内置书源。若旧自建源与新增内置 ID 相同，会保留规则、Cookie 和启用状态，迁移为不冲突的用户 ID。内置书源保持只读，可在“更多 → 管理书源”中复制为自定义书源后修改规则。
网站内容和可用性会变化；若搜索或目录出现错误，请先更换书源，再检查规则。网络实测不纳入默认自动测试，以免网络波动影响本地回归。

新增站点的限制：biquhua 和 biquche 抽查长目录时遇到过超时或 HTTP 500，内置规则将请求间隔设为 2.5 秒以降低连续请求频率。
笔趣阁365 的《红楼梦》原站目录缺第七十二回，实际只有 119 条；抓取器不会补造原站缺失章节。
当前 HTML 引擎尚未支持搜索结果的下一页判定，以上站点的搜索面板只显示首屏结果；目录和正文分页独立处理。
