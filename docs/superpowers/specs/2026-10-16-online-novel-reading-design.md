# 可选在线阅读组件、中文小说书源与按章预取设计

日期：2026-10-16
状态：用户已确认并要求实现；实施与验证进行中（2026-10-17）。

## 1. 用户需求与范围

新增中文小说在线阅读功能：提供核验过的预置书源，允许读者通过表单配置自定义网站，支持搜索、获取目录和提取章节正文。

用户补充要求：**在线功能是额外下载的可选组件**。基础阅读器保留“在线阅读”入口；首次点击时提示需要额外下载安装包，用户确认后才下载并添加功能。取消安装不影响本地阅读，已安装时直接进入在线阅读。不能把爬虫完整编译进基础版后仅用一个开关隐藏。

用户明确要求边读边抓取，默认提前抓取后面 **3 章**。打开小说不以下载整本书为前提。这个需求取代之前讨论的“先下载整本，再开始阅读”。

本设计扩展现有阅读器；2026-09-01 设计中的“在线小说不做”和“完全离线”不再约束此次明确授权的可选在线功能。默认不安装组件、不访问书源、不后台检查或下载组件；基础本地阅读不增加 HTML 解析器依赖。用户确认安装后可访问组件发布服务器，主动使用在线书源时才访问书源网站。

第一版包含：在线小说搜索、目录选择、按章阅读、滚动预取、本地章节缓存、恢复阅读、自定义 HTML 书源、规则测试、错误重试。完整浏览器渲染、脚本书源、全本批量下载和定时追更留待后续。

## 3. 方案选择

采用 **可选独立抓取引擎 + Qt 原生异步网络 + HTML 规则解析 + 独立预取控制器**。

- 只写固定网站适配器：开发简单，但读者无法自行修复改版或增加网站，不能独立满足需求。
- 通用 HTML 规则配合少量 API 适配器：支持读者填表配置，能直接复用 Qt 和本地阅读能力；推荐。
- 引入完整浏览器执行网站脚本：能覆盖更多动态页面，但增加安装体积、内存和维护成本，不作为首版依赖。

抓取引擎以独立的 `reader-online` 可执行程序分发，使用 QProcess 按需启动，通过带请求 ID 的逐行 JSON 协议通信。与把本机动态库直接加载进主程序相比，独立进程能明确隔离依赖、版本边界和解析崩溃，并可在安装成功后立即启用，无需重启主程序。进程只在使用在线书库或在线阅读会话时运行，无会话后退出，不增加常驻服务。

普通 HTML 使用 libxml2 的容错 HTML 解析与 XPath，解析器和书源适配器只存在于额外组件包。表单把规则标为“搜索结果位置”“目录链接位置”“正文位置”，配示例和测试结果，明确规则语法为 XPath。首版不混用 CSS、XPath、正则三套提取语法。

MediaWiki 使用独立适配器处理 JSON 与返回的正文 HTML。主流程依赖统一的搜索结果、目录和章节模型，不依赖某一网站的数据格式。

### 3.1 首次点击、下载与启用

1. 基础程序显示“在线阅读”。没有安装组件时，点击后先显示安装确认框；未安装或已停用组件时，仅显示入口或启动基础程序均不发起在线请求。
2. 确认框说明将添加在线搜索、书源管理和章节抓取，展示组件版本、实际压缩包大小、发布来源、用户目录中的安装位置，以及“下载并启用”和“取消”。基础程序随包携带本次发行对应的组件元数据，因此确认前不必联网查询大小。
3. 用户确认后，异步下载该发行版指定的组件包，显示进度并允许取消。用户仍可继续本地阅读，同一时刻只执行一个安装任务。
4. 下载到临时目录，核验长度、SHA-256、平台/架构、组件协议版本和应用兼容版本，再解包到独立临时安装目录。限制下载及展开后的总大小、文件数，拒绝绝对路径、路径逃逸、符号链接和设备文件。
5. 用组件握手命令检查可运行性与协议兼容；失败时显示具体原因，不启用半安装组件，不修改系统包或要求 sudo。
6. 所有检查通过后原子切换激活记录，立即进入在线书库。再次点击直接打开，无需重新下载确认。

下载或安装被取消、网络失败、磁盘空间不足、校验失败、缺少运行依赖时清理本次临时文件，保留可重试入口和原有可用版本。重新点击时重新显示确认，不在后台自行重试安装。

组件下载仅使用应用发行元数据中的官方 HTTPS 资源地址；普通书源配置不能更改组件下载地址或注入可执行文件。哈希用于验证下载包与随基础程序发布的元数据一致，不把它描述为独立的数字签名。

### 3.2 已安装组件与版本变化

组件管理入口提供已安装版本、占用空间以及“停用”“卸载”。停用或卸载前结束在线请求和子进程；只删除组件代码与私有依赖，保留书源、已缓存章节、书签和阅读进度。基础程序可继续离线打开已缓存的在线书籍，缺失章节显示“需要启用在线阅读组件”。

主程序升级后若协议或兼容版本不满足，点击“在线阅读”时说明需要安装匹配组件，仍经过确认。第一版不后台更新组件。没有对应发行资源时明确显示“此版本暂未提供在线组件”，不能给出失效下载按钮或把安装标记为成功。

## 4. 阅读与预取行为

### 4.1 正常阅读

1. 选择书源，输入书名或作者，显示搜索结果。
2. 选择小说，获取书名、目录及每章的稳定链接。
3. 有阅读记录时请求上次阅读的章节，否则请求第一章；命中本地缓存立即显示。
4. 当前章可读后，按顺序低优先级抓取后面 3 章。当前章不计入“提前 3 章”。
5. 读到下一章后滑动预取窗口，补抓新窗口中缺失的章节；跳过已经缓存或正在请求的章节。
6. 到末尾只抓取实际存在的章节，不越界、不循环、不隐式下载整本。

例：阅读第 10 章时，预取第 11、12、13 章；进入第 11 章后，只需补抓第 14 章。

预取数量在第一版固定为 3，不额外扩展设置项。缓存保留已经读过和已经预取的正文，不因窗口前移删除章节。

### 4.2 跳章与取消

目录跳转到第 N 章时，优先请求第 N 章，并把预取目标改为 N+1 至 N+3。尚未发出的旧预取任务移出队列；与当前目标无关的后台请求可取消。若目标已经在请求中，提升优先级并复用该请求。

切换书籍或关闭在线阅读会话时取消旧会话任务。会话 ID 与书籍 ID 必须同时匹配才能更新当前阅读区；迟到回包不能切换章节、重置新书进度或触发旧书的继续预取。

同一会话单个站点默认最多 1 个在途正文请求。前台章节优先于预取，遵守书源请求间隔，避免重复请求同一章节。网络请求使用 Qt 事件驱动；HTML 解析在工作线程中执行，不运行阻塞式网络等待或嵌套事件循环。

### 4.3 加载和失败

未缓存章节显示“正在加载第 N 章”及取消/重试入口。加载提示是界面状态，不写入正文文件，不参与分页、正文搜索和书签内容。

正文成功后再提交当前章节和阅读位置。等待新章节时保存最后一个实际可读位置；首次恢复阅读的等待过程不能覆盖原有进度。连续翻章时以待加载目标为导航基准，最新选择生效。

当前章失败显示明确错误和“重试”；后台预取失败只更新紧凑状态，不弹出打断阅读的对话框。进入已失败章节时允许再次尝试。网络临时错误最多自动重试 2 次，间隔递增；解析错误和验证页面不自动循环重试。

网络超时默认 20 秒，响应体上限默认 8 MiB；超限立即停止读取。只接受 HTTP(S)，校验 TLS，限制重定向次数；跨站重定向不转发 Cookie 和认证请求头。400/403/404、429、5xx、空正文与规则失效分别给出可辨认的原因；429 尊重 Retry-After。

离线时已缓存章节可读；未缓存章节提示联网后重试，不显示空白章或假成功。自动翻页遇到待加载章节时暂停，加载成功后按原有自动翻页设置恢复，不跳过缺失章节。

## 5. 自定义书源与测试

书源管理支持新增、编辑、复制、启用/停用、删除。预置源可复制成自定义源再修改；已有小说保存书源 ID 和配置快照，删除或修改书源不破坏已缓存内容。

配置表单分三组：

| 分组 | 字段 |
| --- | --- |
| 基本 | 名称、网站基础地址；可选测试用的书籍/目录网址 |
| 搜索与提取 | 搜索 URL 模板（`{keyword}`，可选 `{page}`）、搜索结果项 XPath、每项书名与链接 XPath、可选作者 XPath；可选独立目录页链接 XPath；章节链接 XPath；正文 XPath；可选移除节点 XPath；可选目录下一页与正文下一页 XPath |
| 高级请求 | GET/POST、POST 表单模板、编码（自动/UTF-8/GB18030）、自定义请求头、可选 Cookie、请求间隔（默认 1 秒，至少 0.5 秒） |

搜索模板中的关键词按所选编码编码并进行 URL/表单转义。结果项内部字段使用相对 XPath；链接节点可取 `href` 或字符串结果，统一相对响应最终 URL 解析。配置缺少必须字段、XPath 非法、URL 非法时在表单字段旁说明。

“测试书源”按步骤展示搜索结果 → 目录 → 一章正文，逐步定位失败阶段，并可从书籍 URL 直接测试目录和正文。测试只抓用户选定的一章，不启动预取。

搜索不是必填：没有搜索接口的网站可以保存为“仅网址导入”书源，此时界面隐藏该源的搜索入口，允许直接粘贴书籍/目录网址。第一版的预置源必须支持完整搜索链路。

正文解析保留段落、换行与 HTML 实体，移除 script/style 和指定噪声节点，正文为空即失败。遇到明显的浏览器验证页面，提示“网站需要浏览器验证，当前规则无法读取”。不执行网站返回的脚本。

分页规则未配置时只解析当前页，并在测试界面明确显示该规则状态。配置分页时按顺序合并，同一章多页视为一次逻辑章节获取；目录与正文都记录已访问 URL，防止环路。正文最多 20 页，目录最多 100 页、20,000 个去重章节；超限返回显式错误，不静默保存残缺结果。目录顺序默认页面顺序，可勾选“目录倒序”。

Cookie 只用于用户填写的书源请求，保存在用户可读写的本地配置文件，权限为仅当前用户；错误信息、状态栏和日志不回显敏感请求头或 Cookie。书源记录含 schemaVersion，损坏配置给出错误并保留原文件。

## 6. 预置维基文库适配

通过 Action API 搜索主命名空间，支持结果分页。搜索结果可能是版本页、整书目录、章节或相关文章；不能把所有返回结果都解释为小说目录。

选中作品后解析页面正文中的有序章节链接。遇到包含多个版本、尚无单一章节目录的作品页时，展示版本/目录链接供用户选择；目录最终为空则说明原因，不把作品介绍当第一章正文。

目录过滤导航链接、分类链接、编辑链接、自链接，按最终选定版本的章节路径与页面出现顺序生成章节列表。每章通过 `action=parse` 读取 HTML，再提取实际正文，去掉目录导航及编辑标记。保留来源标题、页面 URL 和必要署名信息。

适配器测试覆盖至少两本小说、简繁体搜索以及包含版本选择的作品，避免仅对《红楼梦》单页成立。联网冒烟测试单独运行，不作为依赖外网的日常测试。

## 7. 模块边界与现有阅读器集成

建议新增核心模块（命名可在实现中按现有风格微调）：

- `BookSource` / `BookSourceStore`：书源配置模型、校验、预置源及原子保存。
- `OnlineComponentManager`：安装确认、异步下载、包校验、原子激活、停用及卸载。
- `OnlineEngineBridge`：管理可选子进程、协议握手、请求/取消/回包及进程退出错误；主程序不动态链接爬虫解析器。
- `HtmlRuleParser`（可选组件内）：无网络的纯 HTML/XPath 解析、正文清洗、链接解析。
- `NovelSourceClient`（可选组件内）：异步 HTTP、限速、超时和错误分类，向 HTML/API 适配器提供响应。
- `OnlineBookStore`：在线书籍元数据、目录、章节缓存、稳定身份与原子落盘。
- `OnlineBook`：实现现有 `Book` 阅读接口，仅返回本地已有正文；同步 getter 不发起网络请求。
- `OnlineReadingController`：当前目标、请求去重、优先级、3 章预取窗口、会话取消与状态信号。

基础程序保留组件安装、界面表单、缓存阅读适配及预取调度，不包含实际网页抓取和 HTML 解析实现。上述控制器通过桥接模块调用可选组件。协议覆盖握手、搜索、目录、章节、取消和退出；消息附协议版本、会话 ID 与请求 ID。设置消息大小上限，损坏 JSON、组件崩溃或退出均变为可重试错误。凭据通过标准输入协议传递，不写入命令行参数；标准输出只承载协议消息，诊断走标准错误且脱敏。

新增 `OnlineLibraryDialog` 和 `BookSourceDialog`，在文件菜单提供统一名称的“在线阅读”入口，在线小说窗口中提供“管理书源”和“在线组件”。使用现有 Qt Widgets 界面风格；阅读正文继续使用现有阅读区，不嵌入网页。

现有接入点：`MainWindow::openBook` 已负责切书与进度恢复；`ReadingView::goToChapter` / `loadChapter` 目前假设正文同步可得；`chapterChanged` 已连接主窗口；最近阅读与书签按本地文件路径标识书籍。

因此需要增加章节可用性与请求状态通道：本地书默认全部可用，在线书可能缺失/加载中/就绪/失败；`ReadingView` 通过控制器请求缺失章节，只有正文就绪才发出已提交的 `chapterChanged`。在线书使用固定本地 `.rnovel` manifest 路径加入 `Book::create` 和最近阅读；该扩展名专用于在线书元数据，文件内容为 JSON，避免与普通 JSON 文件混淆，也避免复制一套书签与进度系统。

“在线书”身份由书源 ID 与规范化作品 URL 生成，章节身份使用规范化章节 URL 的哈希。目录标题、远程 URL、章序号分别存储，不把不可信书名或 URL 直接作为磁盘路径。目录只在首次打开或用户点击“刷新目录”时获取，不后台轮询。刷新时以章节身份映射旧进度，匹配失败保留旧目录并提示，不按变动后的序号静默跳错章。

第一版在线小说进度使用“当前章序号 + 章内阅读比例”，界面标注“按章节估算”；总章节数取目录长度。未下载章节字数未知，不能随缓存增加而改变整书百分比，也不能把已缓存字数当作整本字数。

在线书的“整本搜索”标为“已缓存章节”，只搜索本地已有正文，不因搜索隐式抓取整本。在线书不能进入 TXT 编辑模式。书签继续记录已就绪章节中的位置。

## 8. 数据存储与依赖

使用 `QStandardPaths`：书源配置放在应用配置目录；在线书 manifest、目录和正文缓存放在应用本地数据目录中的 `online/`。这里的正文属于用户离线可读的数据，不放系统可能自动清理的临时缓存目录。

组件安装在应用本地数据目录下 `components/online/<component-version>/`，包含 `reader-online`、新增运行库、组件 manifest 和许可证；与 `online/` 正文数据分开。激活记录保存相对组件路径及版本，不使用 PATH 上同名程序。无需修改 `/usr` 或基础软件包拥有的文件。

书源 JSON、manifest、目录及章节文件使用原子写入，成功解析的正文才能标记为缓存就绪。缓存文件丢失或损坏视为未缓存，可重新抓取；不能因程序崩溃留下的半文件误判已下载。每章独立存储，仅按需载入，避免打开长篇时读取所有已缓存正文。

从最近列表移除记录沿用现有“保留本地数据”的语义。管理书源的删除只删除配置；清理在线正文缓存作为明确操作，不混入最近阅读删除。

已有 Qt6 Network 可用于组件下载及进程内的在线请求。新增 libxml2 只属于可选抓取引擎的构建/运行依赖，不能作为基础 `reader` 或基础 Arch 软件包的强制依赖。组件包随附新增的私有运行库及其许可证，沿用基础程序已需要的 Qt 运行环境；缺失依赖必须在激活前发现。

CMake 增加默认关闭的在线引擎构建选项，基础构建在没有 libxml2 开发包时也能成功。当前 `packaging/PKGBUILD`、`packaging/install.sh` 和 `packaging/build-release.sh` 只安装基础程序；需要扩展发行脚本以单独生成组件压缩包、元数据和校验信息，不能顺带把组件塞入基础安装包。

发行流水线先构建、验证并打包可选组件，再生成包含组件版本、协议版本、兼容应用版本、平台、架构、HTTPS 资源 URL、压缩大小、展开大小上限、SHA-256 的元数据，供同次基础发行打包使用。当前目标平台为 CachyOS/Arch Linux x86_64；不展示未生成的其他架构资源。

本地开发可以导入本次构建生成的组件包以验证完整安装流程；没有发行元数据的源码构建明确显示“未配置组件下载”，不使用占位 URL。组件必须与基础包一起作为独立发行资源发布，才能向最终用户提供真实的一键下载。实现验收需产出本地可审阅的组件包与元数据，发布到远程仍由用户决定。

README 区分“默认本地阅读”与“可选在线阅读”，同时说明组件安装、停用、卸载和离线缓存。程序不增加常驻爬虫或更新服务。

工作区当前有与此功能无关的未提交改动。后续实现应在现有改动基础上精确增量修改，不重置、覆盖或捎带提交这些改动。

## 9. 验证与验收

核心验证使用 Qt Test、本地 HTTP 测试服务器和精简固定 HTML/JSON 样例，不依赖外站实时可用性。

1. 当前第 N 章就绪后，仅请求 N+1 至 N+3，末章边界正确；前进一章仅补一个缺口。
2. 缓存命中和在途请求去重；倒退不重复下载；跳章后前台优先，旧窗口不继续扩张。
3. 切书/关闭/快速连续跳章后，迟到响应不能改变当前书籍或位置。
4. 未缓存章节加载和失败时没有空白假正文，不覆盖有效进度；自动翻页不跨过未加载章节。
5. 断网读缓存、失败重试、超时、限速、取消、超大响应、HTTP 错误及 HTTP 200 验证页均可识别。
6. 搜索 GET/POST、关键词编码、相对 URL、目录倒序、分页去重/防环、段落清洗和无效 XPath 有针对性样例。
7. 配置和缓存重开有效、半文件可恢复、书源编辑/删除保留已缓存阅读能力，敏感请求头不进入日志。
8. 在线书最近阅读、续读、书签、目录跳转和缓存范围搜索有效；已有 TXT/EPUB/MOBI 等本地阅读回归通过。
9. 手工运行 GUI，确认加载期间仍能拖动窗口、翻目录和取消任务；正文显示与当前排版一致。
10. 预置源验收逐一完成搜索 → 目录/版本选择 → 当前章 → 后 3 章 → 重开缓存的真实链路，并如实记录日期与网络失败。
11. 基础构建、基础安装包不包含在线引擎和 libxml2 强制依赖；未安装组件时，启动、未点击入口及取消确认均不产生网络请求。
12. 安装测试使用本地 HTTPS/受控下载测试夹具覆盖确认、进度、取消、校验不符、平台/版本不匹配、超限或恶意路径压缩包、缺少运行库和成功激活；下载发生在确认之后，失败不能留下已启用状态。
13. 已安装后直接打开；停用/卸载终止组件进程而保留阅读数据；主程序升级后不兼容的组件不能被静默启动。
14. 协议握手、请求 ID、取消、乱序回包、超限消息、崩溃和退出可恢复；实际组件包能安装并完成一轮真实在线阅读。

首版验收核心：基础程序不附带爬虫引擎，读者首次点击“在线阅读”并确认后才下载安装可选组件；安装成功即可选书，等当前章加载后阅读，后面 3 章自动准备；可以用表单增加可直接返回 HTML 的中文网站，并在保存前验证规则。
