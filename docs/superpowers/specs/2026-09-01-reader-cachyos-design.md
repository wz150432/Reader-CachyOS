# Reader 原生 Linux 版（CachyOS）设计文档

日期：2026-09-01
状态：已确认，进入实施阶段

## 1. 背景与目标

在 CachyOS（Arch 系 Linux，Wayland / niri 桌面）上提供一款可长期使用的原生桌面阅读器，功能照搬开源项目 [binbyu/Reader](https://github.com/binbyu/Reader) 的本地阅读部分，在线阅读 / 书源爬虫等联网功能不做。用户通过图形界面直接使用，无需命令行。

## 2. 范围

### 2.1 保留功能

**阅读格式**

- TXT：BOM-UTF8 / UTF8 / UTF16 LE / BE / GB2312 / ANSI 等编码自动识别
- EPUB：解压、章节解析、封面渲染（按纯文本方式显示，与原版一致）
- MOBI：通过移植开源 libmobi 解析

**阅读体验**

- 翻页：鼠标左右键点击、鼠标滚轮、方向键、PageUp/PageDown
- 逐行滚动：上 / 下 N 行（N 可配置）
- 自动翻页：翻页与滚动两种模式，间隔可配置
- 章前分页、压缩空行、首行缩进、段距、行距、字符间距、Word wrap 开关

**章节目录**

- 自动解析章节目录（默认解析 + 高级设置中的自定义正则）
- 树形目录、滚轮操作、打开时定位到当前章节、点击跳转

**进度与书签**

- 每本书独立保存阅读进度，重新打开自动续读
- 进度百分比跳转（Ctrl+G）
- 书签添加（Ctrl+M）、书签列表管理与删除

**搜索**

- 关键字搜索并跳转（Ctrl+F）

**显示设置**

- 正文 / 章节标题独立字体、字号、颜色；正文与标题可用同一字体（开关）
- 背景颜色（含取色器）、背景图片
- 窗口透明度（Ctrl+鼠标滚轮）、窗口置顶（Alt+T）、全屏（F11）、隐藏边框（F12）、隐藏窗口（Alt+H）
- 自定义颜色保存

**标签设置**

- 关键字高亮：匹配关键字用指定字体 / 背景色显示

**快捷键**

- 全部快捷键与热键可自定义（按键设置窗口）

**其他**

- 编辑模式（Ctrl+E）：页面文本可修改，退出时可选择保存或取消
- 文件拖拽打开
- 最近阅读列表（阅读列表内可删除单本书）
- 还原默认设置（带确认框）
- 最小化到托盘（用户桌面已运行 Noctalia，支持标准托盘协议）
- 文件关联：双击 txt / epub / mobi 直接使用 Reader 打开
- 标题栏显示当前章节名称

### 2.2 移除功能

- 在线小说（搜索、打开、书源管理、章节刷新）
- 代理设置
- 自动更新检查

### 2.3 与原版的差异

- 完全离线，无任何联网行为
- 系统级全局热键在 Wayland 下受限，优先保证窗口内快捷键全部可用；全局热键按实际测试情况兼容（例如通过 XWayland 生效的部分）
- "隐藏任务栏图标" 在 niri 下意义不大，不实现；保留"关闭窗口 = 最小化到托盘"行为
- 配置与进度文件存放在 Linux 标准目录（见第 6 节），不兼容原版 Windows 数据文件

## 3. 技术选型

- C++17 + Qt 6（Widgets 模块），CMake 构建
- 分页排版使用 Qt 的 QTextLayout 逐行布局引擎，渲染到自绘控件
- EPUB 解压复用开源 miniz；MOBI 解析复用开源 libmobi（原版同款，随项目 vendored）
- 单元测试使用 Qt Test

## 4. 系统架构

```
┌─────────────────────────────────────────────┐
│ MainWindow（菜单 / 阅读区 / 目录侧栏 / 状态） │
├───────────────┬─────────────────────────────┤
│ Book 抽象层    │ Settings / Keyset           │
│ TextBook      │ 显示·基本·高级·按键·标签设置  │
│ EpubBook      ├─────────────────────────────┤
│ MobiBook      │ Cache（进度 / 书签 / 最近）  │
│               ├─────────────────────────────┤
│ Page 分页引擎  │ TagSet 关键字高亮            │
├───────────────┴─────────────────────────────┤
│ 基础：TextCodec 编码识别 / ChapterParser     │
│ 目录解析 / HtmlParser(EPUB) / 第三方 C 库    │
└─────────────────────────────────────────────┘
```

模块职责：

- `Book`：抽象基类，提供章节列表、章节文本、封面、书名等接口；`TextBook` / `EpubBook` / `MobiBook` 各自实现
- `Page`：给定排版参数与窗口尺寸，将章节文本分页；负责翻页、逐行滚动、自动翻页的驱动数据
- `Cache`：按文件路径管理每本书的阅读进度、书签、最近列表
- `Settings`：管理显示 / 基本 / 高级设置与自定义颜色；`Keyset` 管理快捷键与热键映射
- `TagSet`：关键字高亮规则
- 主窗口：菜单、阅读区（自绘）、目录树、书签窗口、搜索条、各设置对话框

## 5. 界面设计

菜单栏（与原版一致，去掉联网入口）：

- 文件(&F)：打开(O)、清空(C)、退出(X)
- 目录(&V)
- 书签(&M)
- 设置(&S)：显示设置、基本设置、高级设置、按键设置、标签设置、还原默认设置
- 帮助(&H)：关于

窗口行为：单窗口阅读器；标题栏显示章节名；支持全屏、置顶、透明度、隐藏边框；隐藏边框时鼠标按住窗口上部拖动；左右键同时按下可配置为隐藏窗口；支持拖拽打开文件。

## 6. 数据与配置

- 设置文件：`~/.config/Reader/config.json`
- 进度 / 书签 / 最近列表：`~/.local/share/Reader/cache.json`
- 全部为本地 JSON，UTF-8 编码，程序退出时原子写入

## 7. 关键算法

### 7.1 文本编码识别

优先级：BOM 检测（UTF-8 / UTF-16 LE / BE）→ 无 BOM 时按 UTF-8 校验，失败则按 GB18030（覆盖 GB2312/GBK/ANSI 常见中文编码）尝试，均失败时退回系统默认编码；读取过程按原版支持的编码表对齐。

### 7.2 章节目录解析

默认解析：按原版规则匹配章节标题行；高级设置支持用户自定义正则。TXT 大文件按流式扫描，不整本载入内存。

### 7.3 分页排版

以 QTextLayout 计算行高与换行，按窗口宽度得出每行文本，按行距 / 段距 / 缩进 / 压缩空行等参数生成页面；"章前分页"开启时每章起始新页。翻页保持整页稳定（不因滚动抖动）。

## 8. 分阶段计划

**第一阶段：TXT 阅读核心**

- 项目骨架（CMake + Qt6，可构建、可运行空窗口）
- 主窗口：菜单栏、阅读区、目录侧栏
- 打开 TXT（多编码识别）、大文件流式读取
- 分页排版渲染与翻页（点击 / 滚轮 / 方向键）
- 章节目录解析、跳转、定位当前章节
- 阅读进度记忆（重开续读）
- 基础显示设置：字体 / 字号 / 行距 / 背景色

**第二阶段：交互与设置补全**

- 搜索（Ctrl+F）、书签（Ctrl+M）、进度百分比跳转（Ctrl+G）
- 显示设置补全：背景图片、透明度、取色器、段距、压缩空行、Word wrap、章前分页、章节字体
- 按键设置（全部快捷键自定义）、自动翻页（两种模式）、逐行滚动
- 标签设置（关键字高亮）
- 窗口行为：全屏 / 置顶 / 隐藏边框 / 隐藏窗口 / 托盘

**第三阶段：格式与集成**

- EPUB（含封面）、MOBI
- 编辑模式、拖拽打开、最近阅读列表、还原默认设置
- 文件关联（txt / epub / mobi）、桌面图标、安装脚本

## 9. 测试策略

- 核心逻辑（编码识别、目录解析、分页计算、配置读写）用 Qt Test 单元测试覆盖
- 每个阶段结束后构建运行，用样本文件（多编码 TXT、EPUB、MOBI）手工验证功能清单
- 向用户展示界面截图，按反馈迭代
